# 🤖 Agentic Workflow System

Complete agentic system with specialized queues, guidelines enforcement, and automatic test/documentation generation.

## 🎯 Overview

The agentic system automatically:
- Routes tasks to specialized queues
- Enforces project-specific guidelines
- Generates tests automatically
- Generates documentation automatically
- Ensures code quality and consistency

## 📊 Specialized Queues

### 8 Queue Types:

1. **code-generation** - Creating new features/components
2. **code-review** - Reviewing and validating code
3. **testing** - Writing and running tests
4. **documentation** - Creating docs and comments
5. **refactoring** - Improving existing code
6. **debugging** - Fixing bugs and issues
7. **deployment** - Releasing and publishing
8. **monitoring** - Tracking and observing

Tasks are automatically routed based on keywords in the task description.

## 🧪 Automatic Test Generation

### Test Frameworks:
- **Python**: pytest
- **JavaScript**: Jest
- **Java**: JUnit 5
- **Kotlin**: JUnit

### Test Structure (AAA Pattern):
```python
def test_feature():
    # Arrange - Setup test data
    data = setup_test_data()
    
    # Act - Execute function
    result = function_under_test(data)
    
    # Assert - Verify results
    assert result == expected
```

### Test Coverage:
- **Unit Tests**: 80% coverage required
- **Integration Tests**: 60% coverage (for web apps)
- **E2E Tests**: 40% coverage (for critical flows)

### Edge Cases Tested:
- Null/undefined values
- Empty values
- Boundary conditions
- Error scenarios

## 🚀 Usage

### From UI:

1. Toggle "🤖 Agentic Mode" checkbox
2. Enter your task
3. Submit

The system will:
- Route to appropriate queue
- Apply project guidelines
- Generate tests
- Generate documentation
- Execute with quality checks

### From API:

```bash
curl -X POST https://broker.fly.dev/api/submit \
  -H "Content-Type: application/json" \
  -d '{
    "project": "diaperstops",
    "task": "Create user authentication endpoint",
    "priority": "high",
    "agenticMode": true
  }'
```

### Response:

```json
{
  "success": true,
  "taskId": "task-123",
  "project": "diaperstops",
  "priority": "high",
  "agenticMode": true,
  "agenticQueue": "code-generation",
  "message": "Task queued in agentic system"
}
```

## 🔧 Configuration

### Custom Guidelines:

```javascript
// In broker server.js
agenticQueue.setProjectGuidelines('myproject', {
  language: 'TypeScript',
  style: 'ESLint + Prettier',
  testing: 'Vitest',
  documentation: 'TSDoc',
  patterns: ['Clean Architecture', 'DDD'],
  security: ['OWASP Top 10'],
  performance: ['Code splitting', 'Lazy loading']
});
```

### Custom Test Requirements:

```javascript
agenticQueue.setTestRequirements('myproject', {
  unitTests: {
    required: true,
    coverage: 90,
    framework: 'Vitest'
  },

```
